# 公开检查清单

此清单用于准备可审阅的分发候选，不执行公开发布。以下各项独立判断，不能由一次检查通过互相代替。

1. **明确文件清单**：只导出审阅过的路径、字节和权限；不复制整个工作目录。排除原始资料、客户记录、运行日志、备份、秘密文件与链接到其它目录的内容。
2. **检查当前内容**：运行 `python3 scripts/check_repo.py --public` 与工具测试；人工复核个人/公司标识、真实业务案例、内部域名和截图。扫描命中只输出位置与类别，公开检查报告也不得携带原敏感值。
3. **另查历史和身份**：当前树干净不能证明旧提交、标签、分支、提交作者/邮箱、提交消息或托管平台附件干净。私有历史含业务资料时，从已核文件构建无旧历史的新候选，不直接改变旧仓库可见性或镜像整个仓库。新公开仓库也会显示所选账号及提交身份，创建前单独确认。
4. **核资料与许可证**：决定哪些自己有权分发；第三方内容按实际许可处理并保留要求的声明。为拟分发内容选定许可证与版权署名；尚未确定时标记未就绪，不把代码可查看当作已获开源许可。
5. **检查实际导出物**：在独立目录验证清单摘要、文本/模式、全部必要依赖以及相同工具测试。候选不包含 `.git`、其它仓库、旧标签、构建缓存或审查私件。证据与清单保存在导出目录之外。
6. **确认具体发布动作**：最终文件、账号/署名、许可证、目标和可见性经过明确授权后才发布；本地准备或历史私有上传授权不自动批准切换公开。

`--public` 只增加联系邮箱、私网端点与原始资料定位串等有限形状检查；不遍历Git历史、不判定资料权利，也不保证发现所有敏感信息。示例保留域名和本地回环地址不表示实际部署。

CI检查成功、服务端强制保护已启用、工具已安装和真实业务交付有效是不同状态。未经验证不宣称“绝对不会泄露”或“失败一定无法合并”。
