# 通用方法与项目知识

本仓库只分发 [gated-delivery](../skills/gated-delivery/SKILL.md)。对外使用名称为“验证驱动交付”，技能标识保持稳定。

| 维护位置 | 内容 | 不能由此推定 |
|---|---|---|
| 通用技能 | 结果定义、独立预期、执行反馈、失败处理、证据与恢复原则 | 项目业务门槛、生产权限或后台调度已经获准 |
| 各项目的约定、技能与配置 | 领域术语、真实输入、参数、数据契约及运行入口 | 可以把该项目的规则施加到其它项目 |

工程任务只读本次需要的领域知识；普通分析不因使用技能而被强制升级为完整研发流水线。安装器只接受本仓库的通用技能，目标中其它技能及链接保持不动。

当前版本 **2.3.1** 增强需求拆解、范围控制和逐项问题闭环。原始材料、逐份学习记录及项目事故不进入通用分发。版本号、文件安装、实际任务效果和远端保护状态分别确认，不能互相替代。
