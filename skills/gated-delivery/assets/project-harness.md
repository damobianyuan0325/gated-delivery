# 项目研发工作约定（按需摘取）

已有 AGENTS.md / 开发说明 / CI 时链接原件，只补缺失约定；不要求另外建此文件。小任务只保留下面前三项即可。

- **目标与边界**：本次可用结果、应拒绝的行为、非目标；已有授权及需人决定的关键取舍。
- **当前入口**：实际源码根、相关项目约定、应优先阅读的入口/数据契约；已有可复用能力、适配边界与原调用方。
- **最小有效检查**：项目现有命令、解释器/依赖、夹具和明确预期；需要的实际层级。

仅复杂或难恢复的任务再补：

- **环境与工具**：构建/测试/本地启动/停止命令；原CI入口与实际强制状态；哪些外部依赖用隔离替身，哪些必须真实验证。
- **执行与协作**：优先主路径、独立工作及写入归属、前置成功条件、预算/停止点。前置失败时停止哪些依赖动作。
- **项目参数与保护**：本项目的业务规则、Schema/接口、期限和资源预算来源；禁止操作、敏感信息边界及副作用处理。
- **证据与恢复**：输出位置、最终源码/执行命令归属、最少必要失败记录；适用的备份恢复入口和未知提交确认方式。
- **续做与验收**：已完成、真实缺项、下一具体动作；关键未决项由谁决定，哪些结果可自动检查、哪些需人工接受或运行观察。不用此文件里的文字代替实际运行。
