# 策略资格、资金与历史身份

只在涉及金融/资源占用、持仓/补偿、余额额度或具有正式运行身份的规则变更时读取；一般研究评分、来源时效或普通开发不自动加载交易流程。保护实际存在的账本、未完成敞口、run/规则身份及当时可得事实。

发射年龄、入场价、持仓intent和正式模拟是条件案例，不是跨项目默认字段。非交易系统按实际资源、历史身份与一致性合同应用相应原则；阈值、规则身份及允许动作由该项目与用户授权决定。

按本页适用条件选用检查，不把某一场景的流程升级为所有任务的默认步骤。

<a id="legacy-l082"></a>

对持续持仓、资源占用或其他长生命周期业务，准入时的安全检查不能替代运行期间的风险回访。沿实际worker验证“明确风险在生命周期中途出现→补偿优先级→请求→结果确认→持久化→用户可见状态”，并覆盖未知、后到证据、执行受阻与重复/并发；明确失败本身不是补偿成功，补偿无法执行时保留原敞口和具体原因。共用实时与历史路径的策略变更必须在两入口使用同一领域行为、记录可得时间与规则身份，不让新补偿成绩混入旧规则。外部数值用于资金或补偿决策前显式校验缺失/null/NaN/Inf/负值/0及单位、身份、来源时效，不依赖单次数值比较默认拒绝非有限值。

<a id="legacy-l084"></a>

同一个价格、容量或资源证据校验被用于准入与补偿时，沿两条实际入口分别构造相同缺失、过期及未来来源反例。退出或补偿已校验该字段，不证明准入也校验；共享函数存在但未被某一分支调用仍属漏口。修复后用一份有效真实录制输入证明没有误伤，再用后到有效输入验证重试可达，不能为了测试绿灯永久拒绝后续合法机会。

<a id="legacy-l086"></a>

用旧缓存保留监控或补偿状态以拒绝未来记录时，缓存标签不能替代原时点可得的真实来源证明。核对对象/身份绑定、原记录时点及当时已确认的来源；selector和reader共用同一证明，或以契约测试证明等价。既保留合法旧状态，也不得把未知缓存或未来首次事实当成已确认状态，反例须分别经过实际选择与读取入口。

<a id="legacy-l100"></a>

采集来源、注册/运行阶段与验证资格属于不同维度时，分别建模和验收，不能用“注册前/背景/历史阶段”代替真实来源。至少覆盖一个明确自然来源但不具备新规则验证资格的实际组合、一个真正事后来源和未知来源；修正统计分类时必须证明资格边界与原冻结记录不被顺带放开，并检查跨版本或跨登记的项目去重。时间资格同时核对首见、发现、决策和当前可得时间，不能用后到或未来输入提升当时判断。选择研究对照时核对发射年龄、研究覆盖及可得时间，时间邻近不等于样本可比；不适用对照标记缺口而不假称完成验证。

<a id="legacy-l102"></a>

验收召回率、命中率、胜率或筛选效果时，真实结果标签必须独立于被评估的预测、信号和准入结论；正负样本使用相同时间窗口、基准和结果阈值。交易收益可以使用实际入场价，但不得把该口径混入以发射价或观察基线定义的机会召回。至少加入一条“未命中但结果为正”的反例，证明漏选分母可达；若结果缺失或不可测，单独统计覆盖率，不能把它排除后宣称零漏选。

<a id="legacy-l116"></a>

扩展平台、模式或业务范围时，沿实际入口检查下游的旧白名单、默认范围和共享校验器；为新增组合经过真实编排入口建立用例，不能以单组件支持替代。涉及按余额、额度或容量判定资格时，测试“刚好足够”和“略低于需求”，不能用“大于零”替代足额；区分预估值与最终事实。

<a id="legacy-l127"></a>

区分正常准入与部分成功后的补偿目标。前者的准入条件不应未经分析直接用于后者；补偿的新额度或风险边界须得到确认，额度按用户指定的业务单元持久化，不能随重试重置。跨平台/提供方只统一业务不变量，不假设它们的重试、幂等或终态响应语义相同。

## 维护与表示变化

涉及迁移、压缩、归档或恢复时，先查真实读写者、Schema/索引、外键与软引用；“派生/已完成”名称不足以证明可删。保护正式 run/规则身份、原资格与累计时长、资金账本及未完成持仓/intent。表示变化须保原字节/原语义摘要与可验证恢复；不能换摘要、隐瞒源码身份变化、倒填历史事实或新建 run 冒原验证连续。写入/删除、发布或重启仍取决于已有授权。
