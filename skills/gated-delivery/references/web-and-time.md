# Web、代理与时间契约

用于真实页面、写路由/代理和跨语言时间展示。选择本次改动对应入口及反例，健康检查不冒完整页面已验。

按本页适用条件选用检查，不把某一场景的流程升级为所有任务的默认步骤。

<a id="legacy-l048"></a>

同源写入校验同时核对scheme与authority（主机、端口），不能只比较Host。测试正常HTTP/HTTPS及同authority异scheme的拒绝；采用服务实际提供的来源语义，不预设代理或转发头。

<a id="legacy-l050"></a>

浏览器经反向代理或TLS终止访问时，先核实际公开入口、后端协议、Host/peer与运行配置；仅直连夹具不能证明代理后的业务可用。需要代理例外时，按明确配置绑定精确公开Origin与实际代理peer，不全局信任Forwarded或移除Origin校验，保留默认直连与错误来源拒绝。部署后沿实际HTTPS入口及适用的IP/本机直连入口验收同一业务，保留跨Host、非批准scheme反例；健康端点200不能代替业务入口验收。

<a id="legacy-l052"></a>

共用Origin helper或少数入口通过，不能替代其它已挂载写路由的接线证明。出现同条件遗漏时，记录直接相关写路由→实际guard→已验层级的有限矩阵，负控穿过真实route→helper→写依赖；分别验证scheme和实际peer，Forwarded不作peer证据。夹具补齐真实必需WSGI字段时保原行为断言及默认生产守卫；未验关联项保partial，不顺带扩大正式源码或操作授权。

<a id="legacy-l056"></a>

跨语言或序列化边界展示时间字段时，明确每字段的单位、类型和时区，以真实生成函数的合法输出穿过实际消费/渲染函数断言具体日期；单独验证生成端与使用手造ISO字符串的页面测试不能证明Unix秒、毫秒或微秒数值正确。修复限定到已证单位的字段，保留来源时钟、有效期及其他格式契约，不凭数量级猜单位或改全局格式化器。

<a id="legacy-l058"></a>

时间标签还须符合实际producer发生阶段：写入前生成的observed或快照时刻，不得标作数据库保存或事务commit时刻。沿真实producer→renderer核对阶段、字段值与标签，缺少独立保存或提交证明时保持未确认；只纠正文案时保原时钟值、来源有效期、缓存及资格规则，不为标签补造持久化时钟。

<a id="legacy-l080"></a>

证据相关页面分别验收复核计划、时间有效性与当前对象/样本适用性。复核到期不等于证据过期，上次样本通过不等于当前样本通过；用实际来源时刻分别测试复核边界、明确有效期及年龄上限，并穿过API序列化和真实页面解释。旧测试若把两个概念合并为同一状态，先纠正需求断言，不能以旧测试通过证明语义正确。

<a id="legacy-l096"></a>

派生DTO或视图的契约测试先沿实际producer核对输出投影：输入记录身份、输出当前值对象与独立证据ID集合分开建模，不能假定输入字段原样保留。缺字段不补造；若失败来自测试前提误读合法投影，保留首失败，仅纠正错误夹具或断言模型并保留其余行为断言，不将测试前提失败当产品事故。

<a id="legacy-l254"></a>

当共用接口或展示组件被多个平台页面采用时，验收要列出各页面实际调用的数据入口与渲染函数，覆盖仍在运行的旧分支。仅给共用组件换平台参数，不能证明旧资金卡、汇总标题或整页请求已采用新语义；关键新旧状态组合要穿过真实页面验证。

<a id="legacy-l256"></a>

页面时间范围和业务标签必须验证同一时间语义。例如“最近一个时间窗内的对象”要明确指发射、首次发现、最近更新还是入库时间，并用超出范围的真实样本做反例测试；不能因为查询使用了某个时间列就默认标签正确。
