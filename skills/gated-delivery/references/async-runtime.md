# 异步、期限与真实终态可达性

用于异步、补发、幂等、外部副作用或持续状态。先画真实触发链，再验证最终效果；未知提交/外部结果不预设失败后重试。

按本页适用条件选用检查，不把某一场景的流程升级为所有任务的默认步骤。

<a id="legacy-l092"></a>

持有连接或锁的执行器还须覆盖清理异常链：rollback或释放锁抛错时，close仍应可达。用同一实际函数注入前置清理异常，验证关闭尝试及异常结果；清理完成不等于业务成功，提交结果不明时保留未知并先做独立只读确认，不盲目重试。

<a id="legacy-l108"></a>

有外部副作用的流程，测试必须穿过首次执行、恢复补发和异常接管入口；检查跨步骤不变量，而不只是各步骤独立通过。 涉及时效或到期资格时，在最终副作用前重新取当前时钟，分别复核原冻结请求与当前适用对象；任务租约仍有效不能替代数据或资格仍有效。构造慢数据库、外部调用或末端控制读取期间跨过截止的反例，分别断言最终执行时刻与副作用次数，不能只用固定时钟证明时效正确。至少选一条实际相关的连续故障链（如部分成功→响应丢失→重启→重复事件），断言副作用次数、不可变请求身份和最终残余状态。测试夹具不得把“未知”预设成“失败/不存在”。

<a id="legacy-l238"></a>

在把纵向功能标为通过前，画出或列出关键状态转换及其**真实触发来源**，并从用户入口逐步证明目标状态可达。需要第二次观察、延时确认、重试、定时任务或队列回访的流程，必须证明实际调度器会产生后续触发；测试中手工调用函数两次不能证明生产会自动调用第二次。成功但空闲的运行周期只证明服务未报错，不能证明下游领取、持久化或状态推进。

<a id="legacy-l240"></a>

事件或周期调度验收同时核对持续需求、处理容量与关键期限，不能只验证一次批量查询的规模/速度或绕过selector的强制刷新。沿来源可得时间→实际selector→reader→提交读回覆盖新事实唤醒、到期任务、未来/已消费事件及既定公平份额；按业务约定区分仍需周期监控、仅到期复核和稳定终态，并证明持续运行时关键期限可达。

<a id="legacy-l242"></a>

异步队列或分阶段任务进入终态前，必须对照“仍未完成”的计数谓词与worker的实际领取谓词：样本类型、状态、租约、重试时间、阶段和版本条件应覆盖同一可处理集合。至少构造一条状态看似pending但不满足领取条件的反例，证明它会被归入明确终态或不进入未完成计数；否则队列数量非零、worker持续空闲的系统不能判定为可完成。

<a id="legacy-l244"></a>

异步任务从首次领取到首个业务进度之间，也须按实际领取、运行状态或已有调用证据区分排队与初始化；尚无阶段进度不能直接判为仍在排队，准备数量为零也不等于已处理结果为零。涉及冷启动或断点恢复的功能，应分别验证冷首入和已有断点路径，不能仅凭请求已提交认定已执行。

<a id="legacy-l246"></a>

新增取消、排队期限或本地请求错误时，沿直接状态消费者分别验证未派发的本地排队、应丢弃的旧上下文，以及已派发请求的真实失败。本地排队不得冒充远端网络或服务异常；状态读取失败也不能抹去已有明确风险或据此刷绿。检查限于本次新增错误的直接入口。

<a id="legacy-l248"></a>

若功能依赖进程内连续状态（连续扫描、窗口累计、节流计数等），验收必须在同一运行实例内跨真实周期完成；两次独立的 `--once`、两次重新构造对象或两次启动命令不能代替连续周期。若需求要求重启后延续，则该状态必须持久化，并另做跨进程恢复测试。测试报告必须明确区分“同实例连续周期”和“跨进程恢复”。

<a id="legacy-l250"></a>

本地服务复验要区分应用故障与执行沙箱网络隔离。若托管进程显示监听端口而沙箱内`curl localhost`失败，先在允许访问宿主机网络的同一入口复验，并对照监听器、进程状态和日志；证据冲突解决前不得把沙箱连接失败写成服务宕机，也不得仅凭监听器存在宣称页面可用。

<a id="legacy-l252"></a>

组合事件流、榜单和轮询快照前，必须记录每个上游的发射语义：一次性事件、可重复快照、增量游标或全量列表。下游若要求连续出现、二次确认或缺席重置，必须用该上游的真实发射方式做组合测试；一次性事件不能靠“下一轮会再出现”的假设满足连续确认。对策略和配置还要做运行读取审计：配置文件中存在的门槛、权重和功能开关，必须有实际入口读取和行为断言，否则标记为未接线，不得在页面或文档中宣称已生效。

<a id="legacy-l272"></a>

持久化“准备执行”不等于外部系统已接收；超时后一次空查询不等于没有副作用。验收要覆盖本地提交记录与外部调用之间的崩溃窗口。时间承诺需测试实际调度和缓存路径，区分目标等待、协作式超时与可强制的期限；不能用配置中的秒数替代测量。
